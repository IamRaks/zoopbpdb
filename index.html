Zone & Region Setup

Configure the zone and authenticate its regions. Summary generation is blocked until setup is complete.

1. Zone
2. BP Regions
3. RD Match
4. Confirm

Select the zone this dashboard represents. Extracted from the ZO column of the FY End BP file. This determines which branches and regions are included in all calculations.

Branches not assigned to any specific region are grouped under this label. It always appears as a region in the dashboard. Default: UNDER ZO.

All unique RO values found in the FY End BP file for the selected zone are listed below. Tick = independent region with its own performance tracking. Unticked = aggregated under the derived region (UNDER ZO). Effective From sets the date from which a region is tracked independently — before this date its branches appear under UNDER ZO.

ⓘ NULL entries represent blank or special-character RO values in the source file.
New RO values (highlighted in amber) were detected in files after the FY End date and require your decision.

Each RD file region must be matched to a BP region so that RD parameters are correctly combined during aggregation. Auto-matched regions (✅) were matched by name — please verify. Unmatched or partial matches (⚠) default to the derived region (UNDER ZO).

ⓘ NULL entries represent blank Region values in the RD file. One-to-one mapping only.

Saving will push configuration to GitHub and trigger a summary rebuild.

⚠ Pending Region Review

New regions have been detected in BP/RD files. Review each item and accept or reject it. Accepted regions require an RD mapping. Rejected regions are permanently grouped under the derived region.
